# План 2c: карточки с интервальным повторением — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Экран `/cards`: карточки латынь↔русский по любой теме (или всем), оценка «не помню / помню / легко», интервальное повторение (упрощённый SM-2), очередь дня (просроченные, затем новые с лимитом), состояние карточек в том же прогрессе, освоение карточек по темам на `/progress`, кнопка «Учить карточки темы» в карточке структуры атласа.

**Architecture:** Чистый модуль `src/lib/srs` (SM-2, очередь, ключ понятия), расширение схемы прогресса (`cards`, `reviews`) с обратной совместимостью, экран `/cards` (React-автомат: setup → review → done), интеграция в `/progress` и `PartCard`. Понятие карточки = латинский термин `la` (сторона игнорируется), русский — из первой части с этим `la`; колода темы — `distinctConcepts(topicParts)`; колода «Все темы» — объединение по всем курсовым темам.

**Tech Stack:** без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-09-22-anatomia-mvp-design.md` §6.3, §6.4, §7, §8.

## Global Constraints

- Ключ карточки: `la` в нижнем регистре с обрезанными пробелами (`cardKey(la)`), одинаковый для обеих сторон и всех мешей.
- SM-2 упрощённый: `ease` 1.3…2.5 (старт 2.5), `interval` в днях, `reps`, `lapses`, `due` (`YYYY-MM-DD` по местному дню, как `dayKey`). Оценки: `again` (не помню) → `interval=1`, `reps=0`, `lapses+1`, `ease=max(1.3, ease-0.2)`; `good` (помню) → reps 0→1: interval 1; 1→2: 3; далее `round(interval*ease)`; `ease` без изменений; `easy` → как good, но interval ×1.3 и `ease+0.15` (≤2.5). Шкала первых интервалов из спецификации (1, 3, 7, 14, 30) получается естественно при ease 2.5.
- Очередь дня: сначала все карточки с `due ≤ today` (в порядке `due`, затем ключ), затем новые (без состояния) в порядке колоды до `newLimit` (по умолчанию 20; настройка хранится в `localStorage['anatomia.cards.newLimit']`), сессия ограничена 50 карточками.
- Прогресс: `ProgressV1` получает необязательные поля `cards: Record<string, CardState>` и `reviews: ReviewSummary[]` (`{ finishedAt, topicId | "all", reviewed, again }`); `parseProgress` подставляет `{}`/`[]` при отсутствии; `normalizeActiveDays` учитывает `reviews[].finishedAt`; версия остаётся 1; экспорт/импорт продолжают работать.
- `/progress`: у каждой темы доля карточек с `interval ≥ 7` («выучено N из M карточек»).
- Dev-сервер пользователя на :3000 не трогать; e2e через `PLAYWRIGHT_BASE_URL`. Коммиты по явным путям с трейлером `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

### Task 1: SM-2, очередь, колода (чистая логика + тесты)

Interfaces:
```ts
export type Grade = "again" | "good" | "easy";
export interface CardState { ease: number; interval: number; reps: number; lapses: number; due: string; lastAt: string }
export interface Card { key: string; la: string; ru: string; topic: string }
export function cardKey(la: string): string;
export function review(prev: CardState | undefined, grade: Grade, today: string): CardState;   // today = dayKey; due = today + interval
export function buildQueue(deck: Card[], states: Record<string, CardState>, today: string, newLimit: number, max = 50): Card[];
export function topicDeck(content: ContentBundle, manifest: AtlasManifest, topicId: string): Card[];
export function allDeck(content: ContentBundle, manifest: AtlasManifest): Card[];   // по courseTopics, без дублей ключей
```
Tests: интервалы good-цепочки 1,3,8(=round(3*2.5)),20,50…; again сбрасывает и снижает ease до 1.3 минимум; easy ×1.3 и ease cap 2.5; due вычисляется через местные дни (использовать `dayKey`/арифметику как в `streakDays`); очередь: просроченные раньше новых, лимит новых, max 50, карточки с due в будущем не попадают; deck: ключи уникальны, ru из первой части, порядок как `distinctConcepts`.
Commit `feat(srs): sm-2 scheduling, daily queue and decks`.

### Task 3: Экран `/cards`

Setup (`data-testid="cards-setup"`): список тем как в квизе + пункт «Все темы» первым; направление (радио «Латынь → Русский» / «Русский → Латынь»); поле «Новых в день» (число, сохраняется); кнопка «Начать» (`cards-start`); под кнопкой «Сегодня: N к повторению, M новых». Review (`cards-review`): лицевая сторона крупно (`card-front`), кнопка/клик «Показать» переворачивает (`card-back` с ru/la + английское имя мелко), три кнопки `card-grade-again|good|easy` с подписями «Не помню / Помню / Легко» и подсказкой следующего интервала («через 1 д / 3 д / 4 д»); счётчик `cards-counter` «Осталось N»; `again`-карточки возвращаются в конец текущей очереди (до 3 раз за сессию, затем остаются на завтра). Done (`cards-done`): «Повторено N, не помню K», «Следующее повторение: <дата ближайшего due>», кнопки «Ещё» (если есть очередь) и «Другая тема». На выходе из review (done/прервать/unmount) — `recordReview` + `saveProgress` (один раз, ref-guard). `?topic=<id>` предвыбирает тему. Header «Карточки» между «Тесты» и «Прогресс». `PartCard`: кнопка «Учить карточки темы» → `/cards?topic=<topicId>` (topicId из `content.structures[partId].topic`; скрыть, если структура не переведена). Headless + `pnpm build`. Commit `feat(cards): flashcards screen with spaced repetition`.
