# План 3: мобильная раскладка и кэш геометрии — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Приложение полноценно работает на телефоне (ширина от 360 px, тач): атлас с выдвижными шторками слоёв и карточки структуры, тесты с панелью снизу, карточки и прогресс с крупными целями касания; собранные BatchedMesh кэшируются между маршрутами, сырые буферы чанков освобождаются после сборки (экономия памяти на телефоне и ~0,65 с при каждом переходе на `/atlas` или `/quiz`).

**Architecture:** CSS-раскладка по брейкпойнту `md` (768 px) без JS-детекции: ниже — панели становятся `Sheet` (шторка снизу, один общий компонент), выше — прежняя раскладка. Тач-управление даёт OrbitControls (одно касание — вращение, два — зум/панорама), клики по модели уже защищены `e.delta > 2`. Кэш геометрии — модуль `src/lib/atlas/batch-cache.ts`: `Map<AtlasManifest, SystemBatch[]>` (ключ — объект манифеста из модульного кэша данных), `BodyMeshes` берёт батчи из кэша и не уничтожает их при размонтировании; `retry()` в `use-atlas-data` очищает оба кэша; после сборки `AtlasData.buffers` заменяется пустым массивом (буферы больше никому не нужны).

**Tech Stack:** без новых зависимостей. Playwright-проект `mobile` (viewport 390×844, `hasTouch`, `isMobile`).

**Spec:** `docs/superpowers/specs/2026-09-22-anatomia-mvp-design.md` §6.1 («Мобильная раскладка: панели превращаются в выдвижные шторки, управление — жесты»), §2 («работает в браузере на ноутбуке и телефоне»), §10 п.6; `docs/superpowers/notes/2026-09-23-followups.md` (кэш геометрии).

## Global Constraints

- Брейкпойнт один: Tailwind `md` (≥768 px — десктоп, иначе — мобильная раскладка). Никакого `navigator.userAgent`.
- Цели касания ≥ 44×44 px на мобильной раскладке (кнопки оценок карточек, «Показать», «Дальше», варианты «назови», галочки слоёв — `min-h-11`).
- Шторка (`Sheet`): `fixed inset-x-0 bottom-0`, `max-h-[60dvh]`, скролл внутри, кнопка закрытия и закрытие по фону; `role="dialog"`, `aria-label`; на десктопе (`md:`) — не используется.
- Канвас: `touch-action: none` (жесты уходят в OrbitControls, страница не скроллится); `100dvh` — уже используется в страницах.
- Существующие `data-testid` не меняются; новые: `layers-toggle`, `layers-sheet`, `part-sheet`, `quiz-panel-toggle`, `site-nav`.
- Кэш батчей живёт в модуле, а не в React; `BodyMeshes` не вызывает `dispose()` для батчей из кэша. Единственная точка очистки — `resetAtlasCache()` (вызывается из `retry`), она уничтожает меши и материалы.
- Память: после успешной сборки батчей `cache.buffers` в `use-atlas-data` заменяется на `[]`; `AtlasData.buffers` остаётся в типе (нужен для первой сборки).
- Dev-сервер пользователя на :3000 не трогать; e2e через `PLAYWRIGHT_BASE_URL`. Коммиты по явным путям с трейлером `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

### Task 1: Кэш геометрии и освобождение буферов

**Files:** Create `src/lib/atlas/batch-cache.ts`, `src/lib/atlas/batch-cache.test.ts`; Modify `src/components/atlas/BodyMeshes.tsx`, `src/hooks/use-atlas-data.ts`.

Interfaces:
```ts
// batch-cache.ts — не импортирует three, чтобы тест был чистым
export interface Disposable { dispose(): void }
export function getCached<K extends object, B extends Disposable>(cache: Map<K, B[]>, key: K, build: () => B[]): B[]; // build один раз на key
export function resetCache<K extends object, B extends Disposable>(cache: Map<K, B[]>): void; // dispose всех и clear
// atlas-level singletons:
export const batchCache: Map<AtlasManifest, SystemBatchLike[]>; export function resetAtlasCache(): void;
```
`BodyMeshes`: `useMemo(() => getCached(batchCache, data.manifest, () => build(data)))`; эффект-деструктор с `dispose` удалить (владелец — кэш). `SystemBatch.dispose()` = mesh.dispose + material.dispose (добавить в объект батча). `use-atlas-data`: после `setState({status:"ready"})` и первого `onReady` буферы освобождать нельзя из хука (сборка идёт в `BodyMeshes`); поэтому `BodyMeshes` после успешного `build` вызывает `releaseBuffers(data)` — экспорт из `use-atlas-data`: `data.buffers.length = 0` только если `data === cache` (полный бандл). `retry` → `resetAtlasCache()` перед `cache = null`.
Tests: `getCached` строит один раз, второй вызов возвращает тот же массив; `resetCache` вызывает `dispose` у каждого и очищает; после reset — новая сборка. Проверка руками: переход `/atlas` → `/quiz` → `/atlas` без повторной сборки (console.time в dev не коммитить). `pnpm test`, `pnpm build`, e2e desktop 14/14.
Commit `perf(atlas): cache built BatchedMeshes across routes, release chunk buffers`.
