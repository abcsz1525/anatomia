# Анатомия

3D-атлас и тренажёр по нормальной анатомии для студентов медвузов.

## Разработка

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm test         # vitest
pnpm e2e          # playwright
pnpm typecheck
```
